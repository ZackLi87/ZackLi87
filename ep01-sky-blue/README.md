## 科学依据（`optics.py`）

画面中的天空、晚霞与太阳颜色并非手工指定，而是按以下模型计算：

- 太阳光谱：5778 K 黑体辐射近似；
- 瑞利散射光学厚度：τ(λ) = 0.008569 λ⁻⁴ (1 + 0.0113 λ⁻² + 0.00013 λ⁻⁴)，λ 单位 μm；
- 光程：Kasten–Young 大气质量公式（天顶角 90° 时约为正午的 38 倍）；
- 颜色：CIE 1931 标准观察者（Wyman 等 2013 年解析拟合）→ sRGB。

计算结果：正午天空 RGB (152, 190, 255)；落日 RGB (255, 109, 0)；450 nm 与 700 nm 的散射强度之比
(700/450)⁴ ≈ 5.86。模型为单次散射近似，未计入气溶胶与多次散射，适用于科普示意。

“比头发丝细十几万倍”按氮分子动力学直径约 0.36 nm、头发直径 50–100 μm 估算。
结尾问题的答案：火星大气中的细尘使晚霞呈蓝色（NASA 好奇号等探测器均有拍摄），可在评论区揭晓。
