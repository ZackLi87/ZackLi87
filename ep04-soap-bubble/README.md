# 第 4 期：肥皂泡为什么是彩色的？

## 科学依据（根目录 `film.py`）

- 泡膜视为空气中的单层水膜（n = 1.33），法向入射，按计入多次反射的艾里公式计算反射率
  R = 2r²(1 − cos δ)/(1 + r⁴ − 2r² cos δ)，δ = 4πnd/λ；再按太阳光谱与 CIE 色匹配函数合成颜色。
- 计算得到的颜色随厚度依次为黑、灰、白、黄、紫、蓝、绿……与肥皂膜干涉色序列一致；
  厚度趋于 0 时反射趋于 0，对应泡泡破裂前顶部出现的“黑膜”。
- 片中泡泡的彩色花纹由厚度场逐像素查表生成（上薄下厚的排液分布 + 缓慢流动的扰动，整体随时间变薄），
  厚度场为示意模型，颜色由计算得到。
