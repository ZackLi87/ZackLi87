# 第 5 期：烟花为什么五颜六色？（第一阶段收官）

约 55 s。片尾向观众征集下一期的问题，用于评估是否继续本合集。成片 `fireworks.mp4`；封面三种比例。

## 科学依据（根目录 `film.py`）

- 焰色由代表性发射谱线／谱带计算：钠 589.0/589.6 nm；锶取 SrOH、SrCl 在 606–682 nm 的谱带；
  钡取 BaCl 在 507–532 nm 的谱带；铜取 CuCl 在 420–452 nm 的谱带。焰火中锶、钡、铜的颜色主要来自
  这些分子谱带，片中为面向儿童的简化表述（“元素发光”）。
- 单色光多在 sRGB 色域之外，显示时按惯例加入白光使其落入色域。钠的计算颜色为橙黄色，与钠光灯一致。
- 烟花为粒子模拟（随机初速度、重力、空气阻力、寿命衰减）。
- 片中附有安全提示：焰色反应实验在教师指导下进行；燃放烟花遵守当地规定，由成人在安全场所进行。
