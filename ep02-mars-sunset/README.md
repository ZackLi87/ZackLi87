## 科学依据

- 火星表面气压约 600 Pa，不到地球的 1%；悬浮尘埃粒径约 1–3 μm。
- 散射按米氏理论计算（根目录 `mie.py`，已用 Bohren & Huffman 的标准算例校验：m = 1.55，x = 5.213，
  Q_ext = 3.105）。尘埃取对数正态粒径分布（中值半径 1.5 μm），折射率 1.52 + ik，k 由 0.012（400 nm）
  降至 0.0015（700 nm），为文献量级的示意参数。
- 计算结果：太阳正前方蓝光（450 nm）散射强度约为红光（700 nm）的 2.3 倍；约 5° 以外红光占优，
  天空呈黄褐色。片中火星日落天空即由该结果逐像素生成。单次散射近似，未计多次散射。
- 火星蓝色日落有 NASA 火星车（勇气号、好奇号等）实拍影像为证。
