## 科学依据

- 水的折射率按 Daimon & Masumura（2007，20 °C）色散公式计算（根目录 `rainbow.py`），
  589 nm 处 n = 1.3334。
- 光线在水滴中折射—内反射—折射，逐条按斯涅尔定律追迹。主虹角：700 nm 为 42.44°，400 nm 为 40.57°，
  与教科书数值（约 42° 与 40°）一致。
- 出射角直方图按入射高度均匀取样、面积权重 b 统计，在最小偏向角（虹角）处出现尖峰，即彩虹最亮之处。
- 片中彩虹由上述分布逐像素计算：对各波长以 0.25° 高斯平滑（代表太阳视直径），再按太阳光谱与 CIE
  色匹配函数合成颜色。因此彩虹内侧偏亮、外侧偏暗，红色在外圈，均与实际一致。未计入副虹与超数虹。
