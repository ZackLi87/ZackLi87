# 镜中自我：一句绕口话的“严格证明”

竖屏短视频（1080×1920，30 fps，约 93 s），面向抖音发布。以“定义—三条引理—结论”的证明结构，
论证命题：

> 别人眼中的自己，不是真的自己；我眼中的别人眼中的自己，才是真的自己。

- 封面：[`cover.png`](cover.png)

## 论证结构

| 段落 | 内容 | 画面 |
| --- | --- | --- |
| 命题 | 引出原句 | 原句分色呈现：紫＝“我眼中的”，青＝“别人眼中的”，橙＝“自己” |
| 定义 | 真实的我记作 X；他人的观察经经历、偏好、情绪过滤，得到像 f(X) | X → 滤镜 → 畸变的 f(X) |
| 引理一 | 同一个 X 在不同观察者处得到互相矛盾的像，故 f(X) ≠ X | 六位观察者给出六种评价 |
| 引理二 | f(X) 位于他人头脑中，不可直接观测；我能接触的只有自己的推测 g(f(X)) | 他人的思维气泡被遮蔽，我的气泡中为 g(f(X)) |
| 引理三 | 换衣服、删消息、会上沉默等行为，由 g(f(X)) 而非 f(X) 决定 | 三个情境指向 g(f(X))，f(X) 被划去 |
| 结论 | 塑造“我”的是 g(f(X))，证毕 | 推导式与结论框 |
| 理论依据 | 库利（C. H. Cooley, 1902）“镜中自我”理论的三个要素 | 三要素卡片 |
| 结尾 | 镜子由自己悬挂，也可由自己擦亮；以提问引导评论 | 雾面镜子被擦亮 |

## 发布文案（供参考）

**标题**：用三步，证明一句很绕的话：“我眼中的别人眼中的我，才是真的我”

**简介**：你在意的，往往不是别人怎么看你，而是你以为别人怎么看你。社会学家库利在 1902 年称之为“镜中自我”。

**话题**：#镜中自我 #社会心理学 #自我认知 #人生感悟 #知识科普

## 重新生成

```bash
pip install -r requirements.txt     # 另需系统中的 ffmpeg
./fetch_assets.sh                   # 下载 Noto CJK 字体与 sherpa-onnx 中文语音模型
python3 make_video.py --cover cover.png
python3 make_video.py --preview 30  # 仅导出第 30 秒的单帧，便于调整版式
```

文案与分镜集中在 `make_video.py` 顶部的 `SCENES`；字幕与旁白默认相同，需要读法不同时写成
`("字幕", "旁白")`。时间轴按每句语音时长自动排布，修改文案后直接重新运行即可。

## 说明

- 旁白为离线语音合成（sherpa-onnx，Matcha 中文模型 + Vocos 声码器），背景音乐由程序合成，
  字体为 Noto Sans/Serif SC（SIL OFL），均无版权限制。如需更自然的配音，可在剪映等软件中
  替换为真人配音或平台内置配音，画面时间轴保持不变。
- 字幕与主要图形置于画面中上部，避开抖音底部文案区与右侧互动按钮区。
- 响度已标准化至约 -16 LUFS（短视频平台常用范围）。
