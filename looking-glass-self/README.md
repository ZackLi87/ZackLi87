# 照见

竖屏短视频（1080×1920，30 fps，约 58 s），面向抖音发布。以水墨、禅意的方式重述一句话：

> 别人眼中的自己，不是真的自己；我眼中的别人眼中的自己，才是真的自己。

- 成片：[`zhaojian.mp4`](zhaojian.mp4)
- 封面：[`cover.jpg`](cover.jpg)

## 文案

| 段落 | 旁白 | 画面 |
| --- | --- | --- |
| 起 | 有人说，别人眼中的你，不是真的你；你眼中的别人眼中的你，才是。 | 一笔圆相，其内渐次叠出淡墨、朱砂两圈 |
| 月 | 千江有水千江月。一千双眼睛里，有一千个你。那些你，你一个也看不见。你看见的，只是自己以为的那一个。 | 一轮月，五道江水各映一月；倒影渐隐，唯余一轮清晰 |
| 常 | 出门前换下的衣裳，发出前删去的那句话，都在回应那个“以为”。 | 衣架、被删去的消息，汇于“以为”二字 |
| 心 | 不是风动，不是幡动，仁者心动。照见你的，从来是你自己的心。 | 风过幡动；“仁者心动”时风止幡静，圆相中现“心”字 |
| 镜 | 心镜蒙尘，处处都是审视；拂去尘埃，别人如何看你，便只是别人的事。愿你照见，本来面目。 | 圆镜蒙尘，一拂而净，镜中现月；落“照见”朱印 |

出处：“千江有水千江月”为禅家常用语；“不是风动，不是幡动，仁者心动”出自《六祖坛经·行由品》；
“本来面目”亦为《坛经》用语。

## 重新生成

```bash
pip install -r requirements.txt          # 另需系统中的 ffmpeg
./fetch_assets.sh                        # 下载 Noto Serif SC 字体与离线语音模型
export MINIMAX_API_KEY=...               # 使用 MiniMax 语音；不设置则使用离线语音
python3 make_video.py --cover cover.jpg
python3 make_video.py --preview 30       # 仅导出第 30 秒的单帧，便于调整版式
```

MiniMax 相关的可选环境变量：`MINIMAX_VOICE`（音色 ID，默认“电台男主播” `Chinese (Mandarin)_Radio_Host`；亦可选“温润男声” `Chinese (Mandarin)_Gentleman`、“抒情男声” `Chinese (Mandarin)_Lyrical_Voice`）、`MINIMAX_MODEL`（默认 `speech-2.6-hd`）、
`MINIMAX_API_HOST`（默认依次尝试 `api.minimaxi.com` 与 `api.minimax.io`）；语速用 `--speed` 调整。
密钥只从环境变量读取，切勿写入仓库。

文案与分镜集中在 `make_video.py` 顶部的 `SCENES`；时间轴按每句语音时长自动排布，修改文案后
直接重新运行即可。

- 背景音由程序合成（Karplus–Strong 拨弦模拟古琴、颂钵、低音持续音），字体为 Noto Serif SC
  （SIL OFL），均无版权限制。
- 文字与图形置于画面中上部，避开抖音底部文案区与右侧互动按钮区。
- 响度已标准化至约 -16 LUFS。
